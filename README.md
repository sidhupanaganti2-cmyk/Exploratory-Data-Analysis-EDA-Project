# Exploratory Data Analysis (EDA) Project

## Overview
This project explores the Titanic passenger dataset to identify patterns, distributions, missing values, and relationships between passenger characteristics and survival outcomes.

## Objectives
- Inspect dataset structure and data quality.
- Calculate statistical summaries.
- Explore survival patterns across passenger groups.
- Visualize age and fare distributions.
- Analyze numerical correlations.
- Generate a structured report with data-driven findings.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Structure
- `main.py` — EDA workflow and visualizations
- `requirements.txt` — Required Python libraries
- `outputs/` — Generated charts, CSV summaries, and report

## How to Run
1. Install Python.
2. Install dependencies with `pip install -r requirements.txt`.
3. Run `python main.py`.
4. Review the generated files in `outputs/`.

## Dataset
Titanic passenger dataset, downloaded from the public DataScienceDojo datasets repository.

## Deliverables
Statistical summaries, data-quality analysis, correlation matrix, visualizations, and an automatically generated EDA report.

## Conclusion
This project demonstrates a structured exploratory data analysis workflow using Python. The findings describe associations within the dataset and should not be interpreted as proof of causation.
